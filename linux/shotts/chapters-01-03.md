2.#Навигация:
	pwd - название рабочего каталога
		cd - выполняет переход в другой каталог
		ls - выводит содержимаое каталога
		.. - cd .. - сменить на предыдущий (родительский) каталог
		"cd -" - сменить на предыдущий (родительский) каталог
		. - cd ./bin - cd bin сменить на дочерний каталог
		cd bin - быстрое перемещение по текущему каталогу
		cd ~username - сменить рабочий каталог на каталог пользователя "username"(имя пользователя)
		ls -a -команда для вывода скрытых файлов
			Нужно проще называть файлы при работе в Linux. Для разделения использовать нижнее подчеркивание, а не пробел.
			
3.#Исследование системы:
	file - определяет тип файла
	less - выводит содержимое файла

	ls - Список содержимого каталога
		ls /usr/bin - содержимое каталога по пути /usr/bin
		ls ~ /usr/bin содержимое каталога по пути /usr/bin и содержимое домашнего каталога /usr
		ls -l (long) - "ls -l /usr/bin" - длинный формат содержимого каталога	
		ls -lt - "-t" - добавлен параметр требующий сортировать результаты по времени изменения
		ls -lt --reverse - "--reverse" - добавлен длинный параметр, чтобы изменить порядок соритровки на обратный
		ls -a - "--all" - отображает файлы (скрытые) с точками в начале имени
		ls -d - "--directory" - выводит дополнительную информацию о каталоге, а не о его содержимом
		ls -F - "--classify" - добавляет в конце имени символ-индикатор
			/ - директория
			* - исполняемый файл
			@ - символическая ссылка
			| - именнованный канал FIFO
			= - сокет
			без символа - обычный файл
		ls -h -"--human-readable" - при использовании long (-l) формата файлов отображает размеры файлов не в байтах, а в в величинах с единицами измерения
		ls -S - сортировать файлы по размеру
		Ввели ls -l:
		-rw-r--r-- 1 root root 3576296 2012-04-03 11:05 Experience ubuntu.ogg
		-rw-r--r-- 1 root root 1186219 2012-04-03 11:05 kubuntu-leaflet.png

		-rw-r--r-- 1 root root 44355 2012-04-03 11:05 logo-Kubuntu.png
		-rw-r--r-- 1 root root 34391 2012-04-03 11:05 logo-Ubuntu.png
		-rw-r--r-- 1 root root 32059 2012-04-03 11:05 oo-cd-cover.odf
		-rw-r--r-- 1 root root 159744 2012-04-03 11:05 oo-derivatives.doc
		-rw-r--r-- 1 root root 27837 2012-04-03 11:05 oo-maxwell.odt
		-rw-r--r-- 1 root root 98816 2012-04-03 11:05 oo-trig.xls
		-rw-r--r-- 1 root root 453764 2012-04-03 11:05 oo-welcome.odt
		-rw-r--r-- 1 root root 358374 2012-04-03 11:05 ubuntu Sax.ogg
		РАЗБОР ПРИМЕРА выше:
			-rw-r--  -Права доступа к файлу. Первый символ указывает тип файла. Например, символом дефиса обозначаются обычные файлы, а символом d — каталоги. 
					Следующие три символа сообщают о правах доступа для владельца файла, следующие три — для членов группы, 
					которой принадлежит файл, и последние три — для всех остальных. Более полное обсуждение прав доступа приводится в главе 9
			1 - число жестких ссылок на файл
			root - имя пользователя владееющего файлом
			root - имя группы владеющей файлом
			32059 - размер файла в байтах
			2012-04-03 11:05 - дата и время последнего изменения
			oo-cd-cover.odf - Имя файла
		Определение типа файлов: file 'название файла.jpeg'
		less - программа для просмотра текстовых файлов
			less команды:
			Page Up или b - прокрутка к началу на одну страницу
			Page Down или Пробел - прокрутка к концу на одну страницу
			стрелка вверх - прокрутка вверх на одну строку
			стрелка вниз - прокрутка вниз на одну строку
			G - Переход в конец текстового файла
			1G или g - переход в начало текстового файла
			/символы - поиск вниз по тексту до ближайшего вхождения указанной последовательности символов
			n - поиск следующего вхождения искомой последовательности символов
			h - вывод экрана со справкой
			q - завершить less
			
		Каталоги Linux:
			/bin - содержит двоичные файлы для загрузки и функционирования системы
			/boot - Содержит ядро Linux образ начального RAM - диска и сам загрузчик. К примеру /boot/grub/grub.conf или menu.lst
			/dev - спец. каталог, содержащий узлы устройств. Здесь ядро хранит список всех известных устройств.
			### Основные каталоги Linux

			- `/etc` — системные конфиги.
				- `/etc/fstab` — точки монтирования.
				- `/etc/passwd` — пользователи.
				- `/etc/crontab` — расписание задач.
			
			- `/home` — домашние каталоги обычных пользователей.
			- `/root` — домашний каталог root.
			- `/tmp` — временные файлы.
			- `/var` — часто изменяемые данные.
			- `/var/log` — системные логи.
			- `/usr/bin` — большинство пользовательских программ.
			- `/usr/local` — ПО, установленное отдельно от пакетного менеджера/дистрибутива.
			- `/sbin`, `/usr/sbin` — системные и административные программы.
			- `/proc` — виртуальная файловая система с информацией о ядре и процессах.
			- `/media` — обычно автоматически подключённые съёмные носители.
			- `/mnt` — место для ручного монтирования.
			- `/opt` — дополнительное стороннее ПО.			
			
		Символические ссылки:
			lrwxrwxrwx 1 root root 11 2012-08-11 07:34 libc.so.6 -> libc-2.6.so
			В системе Linux один файл может иметь два наименования, делается это для удобной работы с разными версиями библиотек. 
			Есть символические (мягкие) и жесткие (hard link) ссылки.
